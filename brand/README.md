# Halftone brand

Generated by `gen_logo.py`; edit the script, not these files. `--embed` refreshes `crates/halftone-report/assets/`; CI runs `--check`.

| Token | Value | Use |
|---|---|---|
| ink-light | `#1B3A5C` | mark, wordmark, verdict glyphs on light |
| ink-dark | `#9CC0E8` | same on dark |
| mono-light | `#000000` | print / single-colour / CLI |
| mono-dark | `#F4F4F2` | same on dark |
| na-grey | `#878783` | NotApplicable only |

Verdict glyphs (`verdict/`): present = solid dot, absent = ring, inconclusive = halftone dot, not_applicable = grey dash. Shape carries the meaning; colour is never required.
